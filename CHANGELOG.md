# Что нового в vysh

Формат: каждая версия - раздел `## [X.Y.Z] - дата`, первая строка `> …` - короткий заголовок релиза.
Группы: `🔒 Безопасность`, `✨ Новое`, `🛠 Улучшено`, `🐛 Исправлено`. CI берёт отсюда текст для страницы релиза.

## [0.6.1] - 2026-11-11
> Диагностика и надёжный запуск обновления Windows

### 🐛 Исправлено
- **Запуск установщика Windows без консольного окна.** Исправлен режим запуска PowerShell, из-за которого фоновый процесс мог создаться, но не начать выполнение скрипта: приложение закрывалось без обновления и перезапуска
- Windows: приложение дожидается подтверждения готовности установщика перед закрытием. Ошибка запуска PowerShell или отмена повышения прав показывается в работающем приложении

- Установщик проверяет завершение старого процесса и содержимое скопированных файлов перед перезапуском. Ошибка копирования не считается успешным обновлением, временные файлы при сбое не удаляются

## [0.5.11] - 2026-11-10
> Русские буквы в Windows-терминале и обновление приложения

### ✨ Новое
- **Проверка и установка обновлений.** vysh следит за релизами на GitHub: раз в 6 часов сам, после возврата из фона и по кнопке в настройках (автопроверку можно отключить переключателем). О новой версии сигнализирует точка на вкладке «Настройки» и всплывающее окно с заметками из CHANGELOG и размером файла; периодичность всплывания настраивается (день / 3 дня / неделю), версию можно пропустить. Установка: файл скачивается с прогрессом и обязательной проверкой SHA-256, затем применяется - на Windows и Linux (portable) с автоматическим перезапуском; на Android после скачивания открывается системный диалог пакетного установщика «Обновить приложение?»; на macOS DMG монтируется, и Finder показывает окно с vysh.app. Ошибка сети не роняет проверку и не жжёт лимит GitHub API

### 🐛 Исправлено
- **Windows: в локальном терминале снова работает ввод с клавиатуры.** Концы пайпов (`inputReadSide` и `outputWriteSide`), передаваемые в `CreatePseudoConsole`, теперь закрываются после `CreateProcessW`, а из `pty_write` убран блокирующий `FlushFileBuffers` на анонимном пайпе
- **Windows: ввод в локальном терминале работает сразу, а оболочка открывается в домашней папке пользователя.** Раньше PTY-плагин дублировал имя исполняемого файла в командной строке, из-за чего cmd запускался как вложенный процесс и блокировал поток ввода, а рабочая папка оставалась директорией программы (где лежит vysh.exe) вместо %USERPROFILE%
- **Windows: русские буквы в локальном терминале больше не мусор.** Нативный код ConPTY раньше копировал команду, рабочую папку и переменные окружения в UTF-16 «побайтово» (и обрезал блок окружения на первой же переменной) - пути и переменные с кириллицей приходили в процесс искажёнными. Теперь UTF-16 собирается через `MultiByteToWideChar(CP_UTF8)`, в ConPTY UTF-8 транслируется самой псевдоконсолью (и `cmd.exe` выводит стандартный баннер без технического `Active code page: 65001`), а при резервном запуске без PTY включается `chcp 65001`
- **Windows: локальному терминалу передаётся полное окружение, и из cmd снова запускаются powershell, wsl и bash.** Раньше PTY-плагин копировал только 6 переменных (`PATH`, `HOME` и другие) и обрезал блок окружения: без `SYSTEMROOT` не запускался WSL, без `COMSPEC`, `TMP` и `USERPROFILE` ломались вложенные powershell и скрипты

## [0.5.4] - 2026-10-16
> Шрифт терминала на выбор

### ✨ Новое
- **Шрифт терминала:** «Настройки → Терминал → Шрифт». В списке только моноширинные шрифты, установленные в системе: vysh находит их сам, в том числе Nerd Font и CJK-шрифты с моноширинной латиницей
- **Свой файл шрифта:** «Добавить шрифт…» и файл `.ttf` или `.otf` до 32 МБ. Шрифт копируется в папку профиля (`fonts/`), переживает обновления и работает везде, включая Android. Если буквы в нём разной ширины, vysh предупредит
- **JetBrains Mono в сборке:** шрифт по умолчанию на macOS и Android вместо системного Menlo и Droid Sans Mono. На Windows и Linux по умолчанию по-прежнему Cascadia Mono, а JetBrains Mono стоит в запасных шрифтах. Вариант без лигатур, два начертания, около 420 КБ
- Межстрочный интервал терминала от 1.0 до 1.6

- **Подтверждение замены при загрузке:** если на сервере уже есть файлы с такими именами, vysh спросит, заменить их, пропустить или отменить загрузку

- **Загрузка не портит файл на сервере:** данные пишутся во временный файл и заменяют прежний только после успешной передачи. Права файла сохраняются, симлинки не превращаются в обычные файлы
- Скачанный файл появляется под своим именем только целиком, а два скачивания с одинаковым именем больше не пишут в один файл

- Настройки вставки: правый клик, средняя кнопка, `Ctrl+V`, подтверждение многострочной вставки

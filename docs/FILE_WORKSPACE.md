# Файловые панели и разделение вкладок

Кнопка с двумя папками в полосе вкладок открывает файловую рабочую область.
В каждой панели независимо выбирается локальный компьютер или готовое
SSH-подключение. Для двух удалённых источников нужно сначала открыть обе
SSH-вкладки. Доступны и две папки одного подключения.

Путь можно ввести вручную; флажки отмечают файлы и папки для копирования.
Стрелки между панелями копируют выделение в текущую папку другой панели.
На узком экране панели располагаются вертикально. Передача отображается
в очереди; её можно отменить.

## Проверка назначения

Копирование обходит вложенные папки. Существующие папки объединяются.
Для файлов одинакового размера содержимое сравнивается побайтово блоками
по 64 КиБ; совпадение даты изменения не считается доказательством равенства.
Одинаковые файлы пропускаются автоматически. Для разных файлов доступны
замена, пропуск, сохранение обоих и отмена. Решение «Применить ко всем»
действует в пределах одной операции, включая вложенные папки.

Данные проходят через временную папку устройства, в том числе между двумя
серверами. Для проверки совпадения скачивается и существующий файл назначения.
Это требует места на диске и трафика; прямой server-to-server режим не реализован.
Временные копии удаляются при успехе, ошибке и отмене. Локальная запись и
SFTP-загрузка публикуют готовый файл после завершения передачи.

Символические ссылки источника пропускаются; ссылки назначения не заменяются.
Файл не заменяет папку и наоборот: такая операция завершается ошибкой без
удаления назначения. Копирование папки в себя или своего потомка запрещено.

Та же проверка используется при загрузке из прежней SFTP-панели и при
скачивании на ПК. Android-публикация в системную Download сохраняет прежнее
поведение с уникальными именами. Автозагрузка локально отредактированного
удалённого файла остаётся отдельным действием.

## Вкладки

Кнопка «Разделить» над терминалом предлагает вторую сессию справа или снизу.
Можно также перетащить вкладку на подсвеченную область слева, справа или снизу.
Активная панель выделена рамкой и заголовком. Разделитель меняет размеры панелей;
двойной щелчок возвращает равные размеры. «Убрать разделение» оставляет обе
сессии открытыми во вкладках. Обычное перетаскивание в полосе меняет их порядок.

В Windows, Linux и macOS перетащите вкладку за пределы окна приложения, чтобы
открыть её в отдельном системном окне. То же действие доступно в контекстном меню
вкладки и кнопкой в заголовке панели. SSH/PTY и история сохраняются без
переподключения. Настройки терминала, темы и сочетания буфера обмена общие.

Кнопка «Вернуть во вкладки» и закрытие отдельного окна возвращают сессию в главное.
Если закрыть главное окно, пока есть отдельные окна, оно скрывается и продолжает
обслуживать сессии; возврат вкладки снова показывает его. Файловые панели из
отдельного окна открываются в общем главном окне. Закрытие вкладки в главном
окне завершает соответствующую сессию и её отдельное окно.

## Свои сочетания

В настройках буфера обмена третья опция «Своя» включает пользовательские
сочетания копирования и вставки. Для записи нажмите соответствующее действие
и сочетание с Ctrl, Alt или ⌘. Конфликты между этими двумя действиями и
основными сочетаниями вкладок отклоняются. Часть системных сочетаний ОС может
перехватить раньше приложения. Есть сброс к стандартным сочетаниям.
Настройки сохраняются в профиле и отражаются в контекстном меню терминала.

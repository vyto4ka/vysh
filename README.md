vysh объединяет в одном окне список серверов, терминал, файловый менеджер SFTP и средства диагностики подключения. Интерфейс построен на Material 3 Expressive с пружинной физикой отклика и подстраивается под цвета системы или рабочего окружения.

## Возможности

### Хосты и вкладки
- Карточки серверов со сворачиваемыми группами, цветными метками и поиском.
- Быстрое подключение: строка вида `user@host:port` в поле поиска и Enter.
- Индикатор доступности хоста (TCP-пинг настраивается в «Настройки → Хосты»).
- Автономные окна вкладок как в браузере: в Windows, Linux (включая Wayland) и macOS перетащите вкладку за пределы окна, чтобы вынести её в отдельное системное окно с сохранением сессии, истории терминала и настроек (`Escape` отменяет перетаскивание). Вкладки свободно переносятся между окнами; перенос последней вкладки закрывает опустевшее окно, а закрытие окна завершает только его собственные вкладки.
- Разделение рабочей области: меню компоновки рядом с вкладками и перетаскивание на подсвеченные зоны размещения открывают вторую сессию слева, справа или снизу (в том числе при переносе вкладки из другого окна). Размер панелей меняется разделителем, двойной щелчок плавно возвращает равные пропорции.
- Плавная горизонтальная прокрутка полосы вкладок колесом мыши или трекпадом; переключение между видимыми сессиями сохраняет разделение окна.
- Массовые действия: несколько отмеченных хостов (Ctrl+клик или долгое нажатие) либо целую группу можно подключить или удалить одной командой.

### Терминал
- Полноценный эмулятор: `htop`, `mc`, `vim`, 256 цветов и truecolor, поддержка мыши.
- Локальный терминал: вкладка с оболочкой текущей системы без SSH. Полноценный псевдотерминал на всех платформах через `flutter_pty` (с резервным `script` на Unix).
- Три режима копирования и вставки: как в Linux (выделение и средняя кнопка мыши), стандартными сочетаниями `Ctrl+Shift+C` / `Ctrl+Shift+V` или своими сочетаниями в режиме «Своя». Вставка по правому клику включается отдельно.
- Сочетания буфера обмена и выделения общие для SSH, локального терминала и отдельных окон.
- Подтверждение перед вставкой нескольких строк, чтобы исключить случайный запуск команд.
- Выделение мышью с автопрокруткой; объём истории настраивается от 1 тыс. до 1 млн строк.
- Шрифт на выбор: любой моноширинный из установленных в системе или свой файл `.ttf` / `.otf`, межстрочный интервал от 1.0 до 1.6. В macOS и Android по умолчанию JetBrains Mono из сборки; кириллица и значки Nerd Font берутся из запасных шрифтов, если их нет в выбранном.
- Переподключение клавишей Enter после обрыва соединения.
- Нагрузка сервера в строке состояния: CPU, память, диск, сеть и время работы (для Linux-серверов).

### Подключение и резервные копии
- Аутентификация паролем, ключом OpenSSH (в том числе с парольной фразой) или стандартными ключами из `~/.ssh`.
- Пароль можно указать в карточке хоста или ввести при подключении, с сохранением или без.
- keyboard-interactive: PAM и одноразовые коды.
- Проверка ключа сервера с предупреждением при первом подключении и при смене ключа.
- Пароли хранятся в системном хранилище: DPAPI в Windows, Secret Service (gnome-keyring, KWallet, KeePassXC) в Linux, Keychain в macOS и Android Keystore.
- Зашифрованные резервные копии профиля (хосты, настройки, при желании пароли и ключи) для переноса между устройствами.

### Файлы и SFTP
- Панель файлов рядом с SSH или локальным терминалом открывается по `Ctrl+Shift+E` (`⌘E` на macOS). Для SSH используется то же соединение.
- Автоматическое слежение за рабочей папкой терминала (переключается в настройках и меню панели): по SSH каталог активного процесса определяется фоново через `/proc` / `lsof` и по сигналам `OSC 7/9;9/1337/633` без вмешательства в `stdin` и файлы сервера; ручной просмотр папок не сбивает последующие `cd`, а кнопка в адресной строке мгновенно возвращает к текущей папке CLI. [Подробности](docs/FILE_WORKSPACE.md#одиночная-панель-и-папка-терминала).
- Навигация в один клик: одиночное нажатие по названию папки сразу открывает её, клик по иконке выделяет элемент, работают интерактивные «хлебные крошки», история `Назад` / `Вперёд` (`Alt+←` / `Alt+→` и боковые кнопки мыши), список дисков Windows (`C:\`, `D:\`), быстрый фильтр `Ctrl+F`, переход по первым буквам, стрелки клавиатуры `↑`/`↓` и сортировка по имени, размеру, дате и типу.
- [Две независимые файловые панели](docs/FILE_WORKSPACE.md): локальные папки, локальный и удалённый источник или два удалённых подключения, плюс буфер `Копировать / Вырезать / Вставить` (`Ctrl+C`, `Ctrl+X`, `Ctrl+V`) внутри сервера и между вкладками.
- При копировании одинаковые файлы пропускаются после проверки содержимого; для отличающихся доступны замена, пропуск и сохранение обоих с применением решения ко всей операции, включая вложенные папки.
- Перетаскивание во все стороны: файлы и папки из ОС загружаются на сервер, одиночные и выделенные группой элементы перетаскиваются наружу, внутрь подпапок (перемещение) или прямо в область терминала (вставка экранированного пути).
- Встроенный текстовый просмотрщик и редактор (`Ctrl+E`, сохранение по `Ctrl+S`) для быстрой правки конфигов и логов на ПК и Android, а также открытие во внешней программе с автозагрузкой обратно при сохранении.
- Скачивание с точным расчётом прогресса и скорости, создание файлов и папок, переименование (`F2`), отменяемое удаление (`Delete`), права доступа (`chmod`, включая setuid, setgid и sticky), команды «Открыть папку в терминале» и «Вставить путь в терминал».

### Диагностика
- Экран ошибки подключения с описанием причины и подробным журналом.
- Ping, трассировка маршрута и проверка порта непосредственно из приложения.

### Внешний вид и анимации
- Material 3 Expressive / Material You, светлая и тёмная темы, 9 акцентных цветов.
- Пружинная физика движения, тактильный морфинг скруглений при нажатии и выборе, сглаженная прокрутка колесом мыши на ПК и круговой переход при смене темы без перестроения открытых терминалов; системная настройка уменьшения движения отключает переходные задержки.
- Темы Catppuccin: Latte, Frappé, Macchiato, Mocha и 14 акцентов.
- Цвета системы: акцент Windows или xdg-desktop-portal (GNOME, KDE).
- Цвета из конфигураций рабочего окружения: caelestia и pywal определяются автоматически, matugen и wallust подключаются через готовые шаблоны. При смене обоев цвета обновляются без перезапуска, подробнее в [docs/THEMES.md](docs/THEMES.md).
- Тема терминала следует акценту приложения, а при использовании цветов окружения берёт их 16-цветную палитру.
- Собственный заголовок окна с вкладками в Windows, macOS, GNOME и KDE; в тайловых оконных менеджерах (Hyprland, sway, i3) используется обычное окно без декораций.
- Экономное потребление ресурсов: отрисовка через Skia (в 2–3 раза меньше памяти, чем с Impeller), пауза анимаций в скрытых вкладках и при свёрнутом окне, фоновые проверки только для видимых элементов; все параметры настраиваются.
- Окно открывается с прежними размером и положением (в Wayland положение определяет композитор).
- Интерфейс на русском и английском языках.

### Android
- Цвета из системной палитры Monet (Material You) или темы Catppuccin; значок приложения в цветах Monet и поддержка жеста предсказуемого возврата (Predictive Back).
- Обычный режим клавиатуры: Gboard и другие клавиатуры запоминают слова, анонимный режим не включается.
- Панель клавиш над экранной клавиатурой: Esc, Tab (`Shift+Tab` по удержанию), Ctrl, Alt, стрелки с автоповтором при удержании, выдвижная строка с Home/End, PgUp/PgDn, Backspace и часто используемыми сочетаниями.
- Контекстное меню выделения в терминале: копировать, вставить, вырезать, выделить всё, стереть строку, поделиться, журнал.
- Сессии сохраняются при сворачивании приложения: активные соединения удерживает системное уведомление.
- Файлы, скачанные по SFTP, сохраняются в общую папку «Загрузки» без запроса дополнительных разрешений; при выдаче доступа к хранилищу в проводнике открывается вся память устройства.

## Установка

### Windows
1. Скачайте `vysh-<версия>-windows-x64.zip` со страницы [релизов](../../releases/latest).
2. Распакуйте архив в любую папку и запустите `vysh.exe`.

> При первом запуске Windows SmartScreen может показать предупреждение о неизвестном издателе.
> Для запуска нажмите «Подробнее», затем «Выполнить в любом случае».

### Arch Linux
PKGBUILD прикладывается к каждому релизу; пакет устанавливается через pacman:
```sh
mkdir vysh && cd vysh
curl -LO https://github.com/vyto4ka/vysh/releases/latest/download/PKGBUILD
makepkg -si
```
Для обновления выполните те же команды в пустой папке. Удаление: `sudo pacman -R vysh-bin`.

Программа устанавливается в `/opt/vysh`, запускается командой `vysh` и появляется в меню приложений. Для хранения паролей требуется Secret Service: `gnome-keyring`, KWallet или KeePassXC.

### NixOS / Nix
Репозиторий содержит `flake.nix` с пакетом, оверлеем и модулями для NixOS и Home Manager. Обновления приходят сразу после публикации релиза.

Быстрый запуск без установки:
```sh
nix run github:vyto4ka/vysh
```

Подключение во флейке системы (NixOS или Home Manager):
```nix
inputs.vysh = {
  url = "github:vyto4ka/vysh";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

В конфигурации NixOS подключите модуль `inputs.vysh.nixosModules.default` (или `inputs.vysh.homeModules.default` в Home Manager) и включите `programs.vysh.enable = true;`, либо добавьте `inputs.vysh.packages.${pkgs.stdenv.hostPlatform.system}.default` в список пакетов. Для сохранения паролей хостов в системе должен работать Secret Service (`services.gnome.gnome-keyring.enable = true;`, KWallet или KeePassXC). Обновление до нового релиза: `nix flake update vysh`.

### Другие дистрибутивы Linux
```sh
mkdir -p ~/.local/opt/vysh
tar -xzf vysh-<версия>-linux-x64.tar.gz -C ~/.local/opt/vysh
~/.local/opt/vysh/vysh
```
Требуются библиотеки `libgtk-3` и `libsecret-1`; в дистрибутивах с графическим окружением они, как правило, уже установлены.

### Android
1. Скачайте APK со страницы [релизов](../../releases/latest): `arm64-v8a` подходит для большинства устройств, `armeabi-v7a` для старых 32-битных.
2. Установите файл, разрешив установку из этого источника.

Новая версия устанавливается поверх предыдущей; хосты и пароли сохраняются.

### macOS
1. Скачайте `vysh-<версия>-macos.dmg` со страницы [релизов](../../releases/latest).
2. Откройте образ и перетащите vysh в папку «Программы».

> Сборка не подписана сертификатом Apple и не нотаризована, поэтому первый запуск macOS заблокирует.
> Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» рядом с сообщением о vysh.
> На macOS 12–14 достаточно ПКМ (Control+клик) по vysh → «Открыть».

Пароли хранятся в Keychain. После обновления macOS может один раз спросить, разрешить ли новой версии доступ к ним: выберите «Разрешать всегда».

### Обновление

В «Настройки → Обновления» можно проверить выход новой версии и установить её из приложения. На Windows (portable ZIP) и Linux (portable tar.gz) архив скачивается с проверкой SHA-256, после закрытия программы файлы обновляются и vysh запускается заново (журнал обновления на Windows — `%TEMP%\vysh_update.log`). В NixOS и системных пакетах Linux (`/opt`, `/usr`) проверка показывает описание новой версии и ссылку на релиз, а само обновление выполняется через флейк или пакетный менеджер. На Android открывается системный установщик APK, на macOS — монтируется образ DMG.

При ручном обновлении достаточно заменить папку программы или перенести новую версию в «Программы» на macOS: хосты, настройки и пароли хранятся в профиле пользователя отдельно от исполняемых файлов.

## Хранение данных

| | Windows | Linux | macOS | Android |
|---|---|---|---|---|
| Хосты, настройки, `known_hosts.json`, добавленные шрифты (`fonts/`) | `%APPDATA%\vysh` | `~/.config/vysh` | `~/Library/Application Support/vysh` | внутреннее хранилище приложения |
| Пароли и парольные фразы | DPAPI (привязаны к учётной записи) | Secret Service (gnome-keyring, KWallet, KeePassXC) | Keychain | Android Keystore |

Файлы хостов и настроек представляют собой обычный JSON без секретов: их можно хранить в git или синхронизировать, например, через Syncthing. Переменная окружения `VYSH_CONFIG_DIR` позволяет запустить vysh с отдельной папкой профиля. При каждом сохранении прежняя версия остаётся рядом в `.bak`.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Новая вкладка / быстрое подключение | `Ctrl+Shift+T` |
| Закрыть вкладку | `Ctrl+Shift+W` |
| Следующая / предыдущая вкладка | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Вкладка по номеру (1 = главная) | `Alt+1…9` |
| Новый хост | `Ctrl+Shift+N` |
| Переподключить | `Ctrl+Shift+R` |
| Панель файлов SSH / локального терминала | `Ctrl+Shift+E` |
| Копировать / вставить | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Настройки | `Ctrl+,` |

Все сочетания включают `Shift`, чтобы не перехватывать у терминала `Ctrl+W`, `Ctrl+R` и другие.

На macOS те же действия выполняются привычными ⌘-шорткатами: `⌘T`, `⌘W`, `⌘1…9`, `⌘N`, `⌘R`, `⌘E`, `⌘C` / `⌘V`, `⌘,`.

Копирование и вставку можно переназначить в настройках буфера обмена, выбрав режим «Своя». Эти настройки действуют и в локальном терминале, и в отдельных окнах.

## Сборка из исходников

Требуется [Flutter](https://docs.flutter.dev/get-started/install) (канал stable). Для Windows дополнительно нужна Visual Studio 2022 с компонентами «Desktop development with C++» и «C++ ATL».

```sh
git clone https://github.com/vyto4ka/vysh && cd vysh
flutter pub get
flutter run -d windows   # или: -d linux, -d macos
```

Релизная сборка для Windows одним скриптом:
```powershell
powershell -ExecutionPolicy Bypass -File tools\build-windows.ps1
# результат: dist\vysh-<версия>-windows-x64.zip
```

Для Linux дополнительно нужны пакеты `ninja-build libgtk-3-dev libsecret-1-dev`; сборка: `flutter build linux --release`.

Для macOS нужен полный Xcode (Command Line Tools не хватит: в них нет `xcodebuild`); релизная сборка с упаковкой в DMG:
```sh
./tools/build_dmg.sh    # результат: build/vysh-<версия>-macos.dmg
```

Для Android требуется Android SDK (устанавливается вместе с Android Studio):
```sh
flutter run -d <устройство>    # отладка
./tools/build_local.sh apk     # APK по архитектурам в build/app/outputs/flutter-apk/
```
Подпись релизного APK описана в [docs/RELEASING.md](docs/RELEASING.md#android).

Для проверки интерфейса и снятия скриншотов есть демо-стенд из пяти SSH-серверов в Docker: [tools/demo](tools/demo/README.md).

### Релизы
Сборки выполняет GitHub Actions: по тегу `vX.Y.Z` в [Releases](../../releases) публикуются архив для Windows, архив для Linux, PKGBUILD, DMG для macOS и APK, а текст релиза берётся из [CHANGELOG.md](CHANGELOG.md). Порядок выпуска описан в [docs/RELEASING.md](docs/RELEASING.md).
